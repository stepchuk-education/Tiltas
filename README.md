# Tiltas

**Tiltas** («міст» литовською) — безкоштовний тренажер для підготовки до державних іспитів Литви:
**литовська мова, I категорія (рівень A2)** і **основи Конституції Литовської Республіки**.
Інтерфейс українською, завдання литовською.

За 6 тижнів користувач «будує міст» на інший берег: кожен день занять — нова дошка.
Поруч — пухнастий друг, який радіє, сумує, коли довго немає занять, і червоніє від помилок.

## Що вміє

- План на кожен день (35–45 хв) з нагадуваннями в календар.
- Діагностика й 13 правил граматики A2: теорія українською, вправи, типові помилки.
- Читання, аудіювання, письмо, говоріння, рольові розмови.
- Три повні тренувальні варіанти мовного іспиту з таймерами (структура — за описом NŠA).
- Основи Конституції: 14 розділів програми NŠA, схеми, числа, пробний тест 20 питань.
- Інтервальне повторення, словник, вкладка «Помилки» з повторною відпрацьовкою.
- Перевірка письма й говоріння з ШІ:
  - на claude.ai — вбудований ШІ-викладач і ШІ-екзаменатор;
  - у звичайному браузері — через безкоштовний чат користувача (кнопка «Перевірити з ШІ через чат»).
- Працює як застосунок на телефоні (PWA) і офлайн.

## Як запустити

Це статичний сайт без збирання: відкрийте `index.html` через будь-який вебсервер,
або увімкніть **GitHub Pages** (Settings → Pages → Branch: `main` → `/ (root)`).

## Структура

| Файл | Що всередині |
|---|---|
| `index.html` | Розмітка, стилі, рамка телефона на комп’ютері |
| `lang.js` | Мовні матеріали: теми, правила, тексти, завдання |
| `konst.js` | Конституція: розділи програми NŠA, питання з номерами статей |
| `exams.js` | Тренувальні варіанти мовного іспиту, факти про іспити |
| `app.js` | Основна логіка: план, вправи, повторення, вкладки |
| `extra.js` | Режим іспиту, помилки, ШІ-викладач, ШІ-вправи |
| `chatai.js` | Безкоштовний режим «ШІ через чат», розпізнавання мовлення браузером |
| `mascot.js` | Персонаж, міст, інтро |
| `pet-rig.js` | Живий Pūkas: дихає, кліпає, махає лапкою, реагує на дотики (WebGL) |
| `pet/` | Зображення персонажа: 21 емоція і головна картинка (`main.webp`) |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA: встановлення на телефон і офлайн |

## Джерела

- Програма іспиту з основ Конституції — Nacionalinė švietimo agentūra (NŠA).
- Опис мовного іспиту, інструкції й пам’ятка для кандидатів — NŠA.
- Текст Конституції — e-seimas.lrs.lt.

Усі завдання в застосунку тренувальні й складені самостійно: це не офіційні завдання NŠA.
Перед іспитом перевіряйте актуальні правила, ціни й дати на сайтах NŠA та migracija.lt.
